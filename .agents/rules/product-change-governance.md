# Product Change Governance

Whenever any product change or feature request is made in this workspace:
1. Follow the `product-change-lifecycle` skill workflow.
2. Execute all 6 stages: Research, Development, Code & Architecture Review, QA Testing, Compliance & Security, SEO Analysis.
3. In Development, ensure `README.md` is updated if necessary (e.g. Catalog entry, tool counts, feature docs).
4. In Code & Architecture Review, conduct an industry-grade interrogation into why architectural and implementation choices were made in a particular fashion.
5. Permit and handle bidirectional issue feedback between all stages.
6. Verify overall lifecycle health with `npm run verify:change`.
